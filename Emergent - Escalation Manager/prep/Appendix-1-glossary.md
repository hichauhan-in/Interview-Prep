# Appendix 1 — Complete Glossary

> **Purpose:** every term defined anywhere in this guide, in one alphabetical place. Use it when a word appears and you can't remember the meaning, without hunting through fifteen files. The **Part** column points to the fuller explanation, with its analogy and its "why it matters."

**How to use:** skim it once after Part B to prime yourself, then treat it as a lookup. If you can define 80% of these cold, your vocabulary is interview-ready.

## The 12 terms most often confused

If you learn nothing else from this glossary, learn these pairs. Interviewers probe them specifically because they separate people who have done the work from people who have read about it.

| Pair | The distinction in one line |
|---|---|
| **Incident vs escalation** | The event vs the handling |
| **Severity vs priority** | How bad (measured) vs what's first (decided) |
| **SLA vs SLO vs SLI** | Promised vs targeted vs measured |
| **Mitigation vs resolution** | Pain stops vs cause removed |
| **Corrective vs preventive** | This instance vs the whole class |
| **Symptom vs root cause** | Fever vs infection |
| **Incident vs problem management** | Restore now vs stop recurrence |
| **CSAT vs NPS vs CES** | Interaction vs relationship vs effort |
| **Refund vs credit vs service credit** | Money back vs future balance vs contractual remedy |
| **Controller vs processor** | Decides why/how vs acts on instruction |
| **Correlation vs causation** | Moving together vs one causing the other |
| **Blameless vs consequence-free** | Honest error is a system finding; recklessness still has consequences |
